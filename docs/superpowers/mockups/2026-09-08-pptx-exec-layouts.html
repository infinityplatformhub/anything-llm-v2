สิ่งที่ mockup นี้ตอบ
  • Layout ใหม่ 3 แบบ: kpi (สไลด์ 2), chart (สไลด์ 3, 5), two-column (สไลด์ 4) บวกหน้าปกและหน้าคั่นแบบใหม่
  • กด "เทียบแบบเดิม" เพื่อดูสไลด์ 2–4 ในหน้าตาที่ระบบสร้างตอนนี้
  • Waterfall (สไลด์ 5) ใช้ bar สีบวก/ลบแทน เพราะ PowerPoint chart มาตรฐานไม่มี waterfall
  • ฟอนต์ในไฟล์จริงจะเป็น Leelawadee UI (Windows) / Sarabun (ถ้ามี) ตัวอย่างนี้ใช้ Sarabun กับ IBM Plex Sans Thai
  • สีเขียว/เหลือง/แดงของ KPI เป็นสีสถานะแยกจากสี theme เพิ่มเป็น token ใหม่ใน themes.js
