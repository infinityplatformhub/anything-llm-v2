MCP Connectors

ยังไม่มี MCP server ใน workspace นี้

เพิ่ม MCP server ของห้องนี้ (HTTP / SSE) หรือเปิดใช้จาก shared catalog ของ instance · stdio ยังตั้งค่าผ่านไฟล์ global เท่านั้น

functions ที่ agent ของ workspace นี้โหลดตอนนี้

ข้อมูลทั้งหมดอยู่ในหน่วยความจำของหน้านี้ · ไม่มีการเชื่อมต่อจริง · รีเฟรชเพื่อเริ่มใหม่

เพิ่ม MCP server

ของ workspace ทีมบัญชี เท่านั้น · รองรับ HTTP / SSE · ค่า secret ถูกเข้ารหัสก่อนเก็บ

Headers
คีย์ที่ชื่อมี token / key / secret / password / authorization / cookie จะถูกปิดบังตอนอ่านกลับ
ต้อง OAuth ต่อ workspace
server ที่ต้องล็อกอิน (เช่น FlowAccount) — หลังบันทึกจะมีปุ่ม Connect บนการ์ด · ไม่ต้องใส่ Authorization header
Tools ที่เปิดให้ agent (จากผลทดสอบ)
วางก้อน mcpServers ที่ vendor แจก หรือ definition เดี่ยว { "url": … } · ตรวจสอบทันทีที่พิมพ์
ยังไม่ได้ทดสอบ

ลบ ?

จะลบ config ของ server นี้ออกจาก workspace ทีมบัญชี รวมถึง token OAuth และสถานะเปิดใช้ ของห้องนี้ด้วย · client ที่กำลังรันจะถูกปิดทันที · ห้องอื่นไม่กระทบ
