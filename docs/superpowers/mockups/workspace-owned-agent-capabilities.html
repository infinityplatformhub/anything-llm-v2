ของเดิมจากระบบ global รายการยังไม่ได้ย้ายเข้า workspace ไหน · เก็บอยู่ที่ storage/plugins/_legacy/
สิ่งที่ mockup นี้ตั้งใจให้เห็น
สลับ workspace แล้วทุกกลุ่มเปลี่ยนตาม · New Workspace ว่างเปล่าทุกกลุ่ม (deny by default) · SQL / Web search กรอก credential ของห้องนั้นเอง ไม่มี “ใช้ค่า global” · MCP process รันแยกต่อห้อง เห็นสถานะต่อห้อง · ปุ่ม legacy import ย้ายของเดิมเข้าห้องทีละรายการ
